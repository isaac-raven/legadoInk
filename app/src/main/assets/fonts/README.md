# 内置字体

本目录用于放置打包进 APK 的阅读字体。**仓库中不包含任何字体文件。**

## 为什么是空的

原工程在此目录内置了三款第三方字体（共约 76MB）。经核查，其中至少一款**不具备再分发授权**：

| 字体 | 大小 | 许可证 | 再分发 | 说明 |
|---|---|---|---|---|
| 京华老宋体（KingHwa Old Song） | 32 MB | **专有授权**<br>`© 2022 TerryWang. All rights reserved` | ❌ **禁止** | 作者为特里王（王廷瑞），基于 1961 年北京新华字模厂 61-1 体制作。发布页标注为专有版权，商用与再分发均需单独取得授权 |
| 霞鹜文楷（LXGW WenKai） | 24 MB | SIL OFL 1.1 | ✅ 允许（需保留署名与许可证） | 开源项目 [lxgw/LxgwWenKai](https://github.com/lxgw/LxgwWenKai)，基于 Klee One |
| 寒蝉活仿宋 | 20 MB | 衍生自霞鹜文楷 | ⚠️ 需自行核实 | 为霞鹜文楷衍生字体，须确认其衍生许可证条款后再决定 |

将专有字体打包进 APK 并随开源仓库分发，构成实质侵权风险。因此本项目**不随仓库分发任何字体文件**，
由使用者自行获取并确认授权。

## 如何获取字体

### 自动下载（仅限确认开源授权的字体）

```bash
./scripts/download-fonts.sh
```

脚本**只会**下载霞鹜文楷（SIL OFL 1.1，明确允许再分发）。其余字体需自行处理。

### 手动放入

将 `.ttf` 文件放进本目录即可。应用启动时会扫描 `assets/fonts/` 并自动出现在「字体选择」列表中，
无需修改任何代码。

### 应用内导入（最稳妥）

应用支持从系统文件选择器导入字体，不打包进 APK 同样可用，也不涉及再分发。
这是使用专有字体的推荐方式。

> 也不提供任何受版权保护字体的下载渠道。
